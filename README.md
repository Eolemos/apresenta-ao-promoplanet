# PromoPlanet · mockups para escolher as cores

Apresentação animada com o **Linktree** (3 cores) e a **Loja** (4 estilos). Tudo é de exemplo: as ofertas são fictícias e nenhum botão entra em grupo de WhatsApp ou em loja de verdade.

**Ver online:** https://eolemos.github.io/apresenta-ao-promoplanet/

## Como abrir no computador

1. Baixe o repositório (Code > Download ZIP) e extraia a pasta inteira.
2. Dê duplo clique em `index.html`. Não precisa de internet nem de instalação (Chrome recomendado).

Os links entre as páginas dependem das pastas: não mova arquivos de lugar.
